Support

For help or a bug report, open a GitHub issue. Please include your device, OS version, source mode, and what happened. Do not attach private audio or account tokens.

What each source does

Local File plays a file you select and draws from its audio on your device. Microphone draws from live input without saving it. Apple Music uses track information and playback position for procedural art; it does not analyze the music stream. Spotify, when configured, shows metadata only and does not drive the visual.

Playback help

If a file will not play, try an MP3 or PCM WAV copy. Format support depends on your device's decoder. Select the file again after reopening the app. Check microphone permission in iPhone Settings if microphone mode is silent.
